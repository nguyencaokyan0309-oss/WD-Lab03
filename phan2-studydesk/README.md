# StudyDesk – Sổ tay học phần

Phần 2 của WDLab03: ứng dụng quản lý mới, theo dõi 11 học phần của một học kỳ cho sinh viên Toán – Tin học.

| Trang | Nội dung |
|---|---|
| `index.html` | Tổng quan: 4 chỉ số, thời khóa biểu tuần (CSS Grid), danh sách sắp đến hạn, tín chỉ theo nhóm |
| `hoc-phan.html` | Bảng 11 học phần, lọc 3 nhóm bằng radio `:checked`, thẻ chi tiết bằng `:target` |
| `dang-ky.html` | Form thêm học phần có validation HTML (`required`, `pattern`, `min/max`, `type=email`) |
| `xac-nhan.html` | Trang thông báo "Đã ghi nhận thông tin" (không lưu dữ liệu) |

Chỉ dùng HTML5 + CSS (`css/style.css`), không JavaScript, không backend. Mở `index.html` trực tiếp (offline) hoặc qua `http://localhost/WD-Lab03/phan2-studydesk/`.
Dữ liệu học phần, mã, phòng và hạn nộp là dữ liệu mẫu tự đặt. Ảnh trong `assets/` là SVG tự vẽ.
